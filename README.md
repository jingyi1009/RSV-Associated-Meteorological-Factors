# RSV-Associated-Meteorological-Factors
This repository contains the data and analysis code used in our study on associations between RSV (Respiratory Syncytial Virus) infections and environmental factors across Japan.

## Data
We uploaded the cleaned version of the data analyzed in our study on the **Data** branch.
The `data` folder includes:
1. **Map of Japan**: Shapefile of Japan.
2. **Prefecture Coordinates**: CSV file containing the longitude and latitude of 47 Japanese prefectures.
3. **RSV and Environmental Data**: CSV file with RSV infection data and related environmental factors across the prefectures.

## Research Content
We provide demonstrations of our research on the **Analysis** branch.
### Main Analyses
1. **Spatio-temporal Analysis**
Descriptive analysis was performed using the demo data, focusing on spatial and temporal trends of RSV infections.

2. **Statistical Models**
Regression analyses examining associations between RSV infections and environmental factors.
  
3. **Predictive Analysis**
Predictive modeling using the GPBoost algorithm to forecast RSV trends.

### Subgroup Analyses
Includes detailed results from subgroup analyses conducted across different geographical groups.

### Sensitivity Analyses
Contains information on the sensitivity analyses we performed to validate the robustness of our findings.
